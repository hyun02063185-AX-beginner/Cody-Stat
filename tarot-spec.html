Tarot

부채꼴로 펼쳐진 22장의 카드를 뽑아 결과를 확인하는 타로 웹앱. 기능 요구사항과, 그대로 복사해서 CC나 Codex에 붙여넣을 수 있는 개발 지시문입니다.

실습 시간 약 30분 카드 수 메이저 아르카나 22장 파일 구성 index.html 단일 파일 도구 Claude Code / Codex

01 프로젝트 개요

정방향 메이저 아르카나 22장으로 진행하는 타로카드 웹앱. 1장 뽑기와 3장(과거·현재·미래) 뽑기 두 모드를 지원하며, 카드 디자인은 세세한 일러스트 없이 이름과 텍스트로만 표시합니다. 별도 서버나 빌드 과정 없이 브라우저에서 바로 열어 실행됩니다.

02 카드 데이터

메이저 아르카나 22장, 정방향 의미만 사용합니다.

03 기능 요구사항

  • 01셔플 애니메이션필수
    카드 뒷면 더미가 나타나면 짧게 좌우로 흔들린 뒤(shake), 카드 배열을 무작위로 섞습니다.
  • 02펼치기(스프레드)필수
    22장을 부채꼴로 펼쳐 배치합니다. 카드마다 다른 회전각·위치를 주고, 순서대로 딜레이를 두며 나타나게 합니다. 22장이 화면 안에 모두 들어오도록 반경·각도·카드 크기를 조정하세요.
  • 03모드 전환 (1장 / 3장)필수
    상단에 토글 버튼 배치. 3장 모드는 클릭 순서대로 "과거 / 현재 / 미래" 자리에 배치하고 라벨을 표시합니다. 별도 랜덤 함수 없이 셔플 단계에서 이미 섞인 배열을 그대로 사용합니다.
  • 04뒤집기필수
    선택된 카드가 확대되며 뒷면→앞면으로 뒤집힙니다(CSS 3D transform).
  • 05결과 표시필수
    카드 이름(로마숫자·영문·한글)과 키워드 의미를 표시합니다. 3장 모드는 종합 해석 없이 자리별로 개별 나열만 합니다.
  • 06다시 뽑기 버튼필수
    결과 화면 하단, 클릭 시 셔플 전 상태로 리셋합니다.

04 범위에서 제외

  • 역방향(리버스) 카드 해석
  • 마이너 아르카나(완드·컵·소드·펜타클) 카드
  • 정교한 카드 일러스트 이미지
  • 여러 장을 하나의 서사로 종합하는 AI 생성 해석 (외부 API 호출 없음)

06 진행 팁

  • 한 번에 전체를 요청하기보다 펼치기 → 뽑기 → 뒤집기 순으로 단계를 나눠 확인하며 진행하면 막힌 지점을 짚기 쉽습니다.
  • 버그가 보이면 "이어서 해줘" 대신, 화면에 보이는 증상을 구체적으로 설명해 주세요 (예: "22장 중 일부가 화면 밖으로 벗어나 안 보임").
  • 버튼이 카드 스프레드에 가려지는 등 레이아웃 겹침 이슈가 흔하니, 먼저 확인해보면 좋습니다.
