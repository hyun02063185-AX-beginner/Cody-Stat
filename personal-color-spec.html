Vibe Coding Practice · 02

Warm / Cool

사진 속 피부 톤을 클릭 한 번으로 읽어, 웜톤인지 쿨톤인지 재미로 알려주는 웹앱. 기능 요구사항과, 그대로 복사해서 CC나 Codex에 붙여넣을 수 있는 개발 지시문입니다.

실습 시간 약 30분 입력 방식 사진 업로드 · 카메라 촬영 파일 구성 index.html 단일 파일 도구 Claude Code / Codex

01 프로젝트 개요

사용자가 사진(업로드 또는 촬영)을 올리고, 사진 속 피부 부분을 클릭하면 해당 지점의 색상을 분석해 웜톤/쿨톤을 판정하는 웹앱입니다. 서버 전송 없이 브라우저 안에서만 처리되며, 정식 진단이 아닌 재미용 테스트로 설계합니다.

WARM

노란빛·주황빛에 가까운 색상. 골드 액세서리, 아이보리 계열이 잘 어울리는 쪽.

COOL

핑크빛·파란빛에 가까운 색상. 실버 액세서리, 화이트 계열이 잘 어울리는 쪽.

02 기능 요구사항

  • 01사진 입력필수
    <input type="file" accept="image/*">로 기존 사진 업로드. 모바일에서는 capture 속성으로 바로 카메라 촬영도 가능하게 합니다.
  • 02사진 미리보기필수
    업로드한 사진을 canvas에 표시합니다.
  • 03클릭 지점 색상 추출필수
    사용자가 사진 위(뺨 등)를 클릭하면, 해당 좌표의 픽셀을 getImageData로 읽어 RGB 값을 추출합니다.
  • 04RGB → HSV 변환 및 판정필수
    추출한 RGB를 HSV로 변환하고, Hue 값이 노란빛/주황빛에 가까우면 웜톤, 핑크빛/파란빛에 가까우면 쿨톤으로 분류하는 함수를 구현합니다.
  • 05결과 화면필수
    판정 결과(웜톤/쿨톤)와 함께 어울리는 컬러 팔레트 스와치(4~6개)를 보여줍니다.
  • 06안내 문구필수
    "정식 퍼스널컬러 진단이 아닌 재미로 보는 테스트"라는 문구를 화면에 표시합니다.
  • 07클릭 지점 확대 표시선택
    클릭한 지점 주변을 확대해 보여줘서 정확한 위치를 클릭하도록 유도합니다.
  • 08다시 테스트하기 버튼선택
    클릭 시 처음(사진 업로드 전) 상태로 리셋합니다.
사진은 서버로 전송되지 않고 브라우저 안에서만 처리됩니다 — 이 점을 화면에 짧게 안내하면 신뢰도를 높일 수 있습니다.

03 범위에서 제외

  • 얼굴/피부 영역 자동 인식(face-api.js 등 라이브러리)
  • 서버 저장 또는 외부 AI API를 연동한 문장형 해석 생성
  • 정밀한 색채학 기준의 진단 (재미용 테스트 수준으로 제한)

05 진행 팁

  • 입력 → 클릭 색상 추출 → 판정 로직 → 결과 화면 순으로 단계를 나눠 확인하며 진행하면 좋습니다.
  • 조명이나 사진 화질에 따라 결과가 흔들릴 수 있어서, 발표 시 "재미로 보는 테스트"라고 미리 안내해두면 결과가 안 맞아도 자연스럽게 넘어갈 수 있습니다.
  • 웹캠 실시간 스트림(getUserMedia)은 권한 요청·미러링 처리로 코드가 늘고 라이브 중 권한 거부 위험이 있어, 실습에서는 파일 업로드 방식을 우선 추천합니다.
