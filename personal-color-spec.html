Vibe Coding Practice · 02

Warm / Cool

얼굴 사진을 올리면 자동으로 피부 톤을 읽어 웜톤·쿨톤을 판정하고, 그에 맞는 메이크업·의상·헤어 컬러까지 제안하는 웹앱. 기능 요구사항과, 그대로 복사해서 CC나 Codex에 붙여넣을 수 있는 개발 지시문입니다.

실습 시간 약 30분 입력 방식 사진 업로드 분석 자동 판정 파일 구성 index.html 단일 파일 도구 Claude Code / Codex

01 프로젝트 개요

사용자가 얼굴 사진을 업로드하면, 클릭 없이 자동으로 피부 영역을 찾아 색상을 분석해 웜톤/쿨톤을 판정합니다. 결과와 함께 어울리는 메이크업 색상·의상 색·헤어 염색 컬러를 스타일링 조언으로 제안합니다. 서버 전송 없이 브라우저 안에서만 처리되며, 정식 진단이 아닌 재미용 테스트로 설계합니다.

WARM

노란빛·주황빛에 가까운 색상. 골드 액세서리, 아이보리 계열이 잘 어울리는 쪽.

COOL

핑크빛·파란빛에 가까운 색상. 실버 액세서리, 화이트 계열이 잘 어울리는 쪽.

02 기능 요구사항

  • 01사진 업로드필수
    <input type="file" accept="image/*">로 얼굴 사진을 올립니다. 업로드된 사진은 canvas에 표시합니다.
  • 02사진 촬영 자리 확보자리만
    업로드 버튼 옆에 "사진 촬영" 버튼을 비활성 상태로 배치합니다. 클릭하면 "준비 중" 안내만 표시되고, 실제 카메라 기능은 이번 실습 범위에서 제외합니다. 나중에 이 자리에 촬영 기능을 붙일 수 있도록 UI 자리와 함수 껍데기만 만들어 둡니다.
  • 03피부 영역 자동 탐지필수
    클릭 없이 자동으로 얼굴/피부 영역을 찾습니다. 얼굴이 사진 중앙에 오는 일반적인 인물 사진을 가정하고, 중앙 영역을 후보로 잡은 뒤 피부색 범위 필터(RGB/HSV 기준으로 피부에 해당하는 색 범위)를 적용해 배경·머리카락·옷을 걸러냅니다.
  • 04다중 샘플링 및 평균필수
    한 픽셀만 보지 않고 피부로 판정된 여러 지점의 색상을 모아 평균을 냅니다. 그림자·하이라이트로 튀는 극단값은 제외해서 안정적인 대표 색상 하나를 만듭니다.
  • 05웜/쿨 판정필수
    대표 RGB를 HSV로 변환하고, Hue가 노란빛·주황빛에 가까우면 웜톤, 핑크빛·붉은빛·푸른빛에 가까우면 쿨톤으로 분류합니다. 판정 근거로 추출된 대표 색상 스와치도 함께 보여줍니다.
  • 06결과 화면필수
    판정 결과(웜톤/쿨톤)와 어울리는 기본 컬러 팔레트 스와치(4~6개)를 표시합니다.
  • 07스타일링 조언필수
    판정 결과에 따라 메이크업 색상 / 의상 색 / 헤어 염색 컬러 세 가지 항목의 조언을 카드 형태로 보여줍니다. 각 항목마다 실제 색상 스와치와 짧은 설명을 함께 표시합니다.
  • 08안내 문구필수
    "정식 퍼스널컬러 진단이 아닌 재미로 보는 테스트"라는 문구와, 사진이 서버로 전송되지 않는다는 안내를 표시합니다.
  • 09다시 테스트하기 버튼선택
    클릭 시 처음(사진 업로드 전) 상태로 리셋합니다.
  • 10탐지 실패 처리선택
    피부 영역을 찾지 못했을 때 "얼굴이 잘 보이는 사진으로 다시 시도해 주세요" 같은 안내를 표시합니다.
사진은 서버로 전송되지 않고 브라우저 안에서만 처리됩니다 — 이 점을 화면에 짧게 안내하면 신뢰도를 높일 수 있습니다.

04 범위에서 제외

  • 사진 촬영 기능 — 버튼 자리만 잡아두고 동작은 구현하지 않음
  • 실시간 웹캠 스트림 (getUserMedia)
  • 외부 얼굴 인식 라이브러리 로딩 (face-api.js, MediaPipe 등) — 색상 범위 필터 방식으로 처리
  • 서버 저장 또는 외부 AI API를 연동한 문장형 해석 생성
  • 정밀한 색채학 기준의 사계절 진단(봄·여름·가을·겨울 세부 분류) — 웜/쿨 2분류까지만

06 진행 팁

  • 업로드 → 자동 피부 탐지 → 판정 → 스타일링 조언 순으로 단계를 나눠 확인하며 진행하면 좋습니다.
  • 자동 탐지는 클릭 방식보다 결과가 흔들릴 여지가 큽니다. 실습 전에 얼굴이 크고 조명이 균일한 사진 한두 장을 미리 준비해 두면 시연이 안정적입니다.
  • 판정이 이상하게 나오면, 추출된 대표 색상 스와치를 먼저 확인해 보세요. 색이 피부색과 동떨어져 있으면 피부색 필터 범위가 문제이고, 색은 맞는데 결과가 어색하면 웜/쿨 경계값을 조정하면 됩니다.
  • 결과가 조금 안 맞아도 괜찮도록, 처음부터 "재미로 보는 테스트"라고 안내해 두는 편이 좋습니다.
